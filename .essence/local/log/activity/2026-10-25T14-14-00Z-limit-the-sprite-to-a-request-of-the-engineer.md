# Limit the sprite to a request of the engineer

## Activity

The agent changed the sprite section of `AGENTS.md`, so that the work of an endeavor is done in a sprite only at the request of the engineer: "actually just requested by demand". The activity belongs to no endeavor.

## Work products

- `AGENTS.md` — changed: the new R1 of the sprite section, the new numbers of the setup rule and the token rule, and the title, an example, and the rationale of the section

## Decisions

- R1 states the request as a permission: "may be done in a sprite only if the engineer requests a sprite for the endeavor". A delegation does not request a sprite. The engineer first wrote "only for delegated endeavor or if requested by demand", and then removed the delegated endeavor.
- The setup rule is now R2, and the token rule is now R3. Each example names its new number.
