# Give the URL of the sprite in the pull request of a delegation

## Activity

A change of a local rule, at the request of the engineer: "I think the PR should have this URL: give-the-url-of-the-sprite-in-the-report-of-a-delegation", and "if a PR exists then add it".

## Work products

- `.essence/local/rules/the-report-of-complete-delegated-work-gives-the-url-of-its-sprite.md` — changed: the title, R2 for the description of a pull request, the new R3, two examples, and the Rationale
- the description of the pull request https://github.com/nicholasjhenry/essence-harness-sandbox/pull/4 — changed: the section "Try it" with the URL of the sprite

## Agent skills

- rule-speak
- simplified-technical-english
- version-control

## Decisions

- R3 is a rule of its own, and not a condition of R1, because R1 constrains the report and R3 constrains the description of the pull request.
- R3 applies to each pull request of the work branch that exists, and not only to a new one. The engineer requested: "if a PR exists then add it".
- The file name of the rule does not change. Its title names the pull request too. A new name would break each reference to the rule in the log.
- The agent applied R3 to pull request 4, which was open with no URL of the sprite.
