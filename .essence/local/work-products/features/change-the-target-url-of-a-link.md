# Change the target URL of a link

## Request

The owner of a link changes its target URL, and the short code stays the same. Today the owner deletes the link and shortens the new target URL, and the short URL of the deleted link resolves to no target URL. The domain walkthrough adds the event of the change, and decides who can make it.
